# 发布验收清单

此文件是可复用的测试步骤，不代表每个环境和每次构建都已经通过。真实测试结果应记录在对应 Release 或 PR 中，个人诊断日志不提交到公开仓库。

## 自动化

- [ ] `npm ci` 可以从锁文件安装依赖。
- [ ] `npm run typecheck`、`npm test` 通过。
- [ ] `npm run build`、`npm run test:ui` 通过。
- [ ] `npm run package:win` 通过安装包完整性检查。

## 安装与生命周期

- [ ] 新用户安装后能进入首次设置，并填写凭据。
- [ ] 选择父目录后自动补全产品文件夹，安装到期望路径。
- [ ] 自动 / 手动打开 Codex 正常，沿用既有登录状态。
- [ ] 已有独立桌面时先提示并确认，再重启连接。
- [ ] 重复打开应用不产生多个托盘图标；关闭行为与偏好一致。
- [ ] 开机启动开关设置后可读取真实状态。
- [ ] 有任务运行时按产品提示处理退出，空闲时可退出全部自有服务。
- [ ] 升级与保留数据重装可恢复连接；不同安装路径也能恢复。
- [ ] Release 同时包含安装包、`.blockmap` 和同次构建的 `latest.yml`；上一版应用能发现、下载并在确认后安装新版。
- [ ] 更新安装时运行中的任务阻止退出；取消退出后安装包不启动，稍后可再次安装。
- [ ] 卸载后原版 Codex 可独立使用，登录、历史和项目保留。
- [ ] 勾选清除数据只清理本应用数据；不勾选则重装后可恢复。
- [ ] 自带 Skill 仅在归属与内容校验通过时清理，个人修改保留。

## 双端接续

- [ ] 桌面开始一轮，飞书继续同一线程，历史连续。
- [ ] 飞书开始一轮，桌面继续；切换会话不停止旧任务或串线。
- [ ] 新建会话后设置模型 / 强度可以正常发送。
- [ ] 工作台历史预览不占用独立桌面的空闲历史会话。
- [ ] 当前会话名、项目、模型和强度可辨认。
- [ ] 消息提交后断线不会自动重发，恢复后可查看实际结果。

## 飞书

- [ ] 未授权账号被拒绝，允许账号后正常收发。
- [ ] 进度更新、完成结果展示和选择按钮正常。
- [ ] 自动通知默认关闭；开启后按范围与时长过滤。
- [ ] Codex 第一条中途说明立即显示进度卡，后续更新原卡；没有中途说明时，等待再久也不创建进度卡。
- [ ] 有进度卡时原卡展示最终结果，没有进度卡时正常发送结果；不撤回、不重复发卡。结果送达后原消息保留“完成”表情，核对手机提醒。
- [ ] 同轮补充消息共用一张进度卡与一次完成提醒；失败、停止和送达未确认时不标完成；表情失败不重发已送达结果。
- [ ] 显式 MCP 通知正常，与自动通知不重复；卡片点击后才切换会话。
- [ ] 图片 / 文件仅在明确要求时发送；普通改代码不会上传源码。
- [ ] 密钥验证失败保留原连接，凭据不出现在页面与日志中。

## 兼容性记录

发布说明中记录 Windows、官方 Codex、Node.js 和应用版本。官方 Codex 更新后，重点复测单次启动、登录状态、会话归属、工具转发和退出清理。macOS / Linux 当前不在支持范围内。
