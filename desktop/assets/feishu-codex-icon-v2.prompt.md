# Feishu Codex 图标方案 v2

使用内置 imagegen 生成。定位：通过飞书对话接续 Codex 桌面的同一任务。对话气泡代表消息，终端符号代表代码执行，折角代表连接。

图片：feishu-codex-icon-v2.png。已采用扁平圆角版本作为应用图标源文件；scripts/generate-icon.ps1 从此图生成窗口、托盘及安装包使用的 PNG 和多尺寸 ICO。

## 生成提示词

Use case: logo-brand.
Asset type: one finished square application icon / Feishu bot avatar, not a presentation sheet.
Primary request: Design an original premium icon for "Feishu Codex", a lightweight local Windows companion that connects Feishu mobile conversations to the same coding-agent tasks used in the Codex desktop app. Positioning: conversation directly drives code; seamless continuation across devices; focused, friendly, dependable. Represent this as ONE memorable integrated symbol, not separate device illustrations.
Visual: rich deep cobalt-to-indigo full-bleed square background, very subtle smooth gradient. At the center, a bold warm-white rounded speech-bubble silhouette with a short elegant folded tail that subtly suggests a connection or a paper-plane wing. Inside its white body, cut a thick dark-indigo terminal chevron ">" and a short thick mint-teal underscore "_". The glyphs should be centered with optical balance and generous spacing, legible at 32 pixels. The speech bubble is the primary silhouette; the tiny fold/return in its tail conveys connection without adding a second busy symbol.
Style: polished modern desktop application identity, restrained soft dimensional finish with a slight edge highlight, predominantly clean flat shapes, crisp curves and subtle depth, no plastic inflated toy look, no glass reflections. Excellent bold silhouette, distinct and calm. Large centered emblem occupying about 64% of the square; keep generous padding safe for circular avatar cropping. Perfectly front-facing.
Constraints: one icon only, square canvas, full-bleed background without external mockup or outer margins. No words, no application name, no letters except the terminal punctuation ">_". No watermark, no device screens, no cables, no robots, no gears, no stars, no decorative particles, no official Feishu bird logo or OpenAI knot, no border text, no montage. Produce a production-quality high-resolution PNG image.
